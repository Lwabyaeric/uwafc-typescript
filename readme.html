UWA FC Web Portal & PWA

Official Executive Platform — Multi-Page Routing Documentation

1. Executive Summary

This web application delivers real-time match data, roster changes, and club metrics for Uganda Wildlife Authority Football Club (UWA FC). Built as a Progressive Web Application (PWA) with a structured multi-page routing system, the platform seamlessly segments institutional corporate governance from football performance analytics.

Club Identity Integration

  • Primary: Corporate Deep Green
  • Secondary: Savannah Gold Accent
  • Dynamic Favicon: Circular auto-masked badge layout built dynamically via JavaScript canvas matrices.

PWA Configurations

  • Identity: uwa fc (Strict Standalone App)
  • Navigation: Router-integrated caching for subpages
  • Theme Syncing: System-wide navigation bars mapping institutional assets.

2. Routing Matrix & Site Architecture

The platform relies on client-side routing to handle instantaneous multi-page transitions, allowing deep-nested subpages to load efficiently under a unified system shell.

/ (Homepage - Match Center & Live Metrics)
├── /about (Institutional Profile)
│   └── /about/board (Executive Management & Patron's Message)
├── /squad (The Club Matrix)
│   ├── /squad/technical-bench (Coaches & Physiotherapists)
│   └── /squad/players (Goalkeepers, Defenders, Midfielders, Forwards)
├── /fixtures (Performance Center)
│   └── /fixtures/table (Live League Standings)
└── /community (CSR & Wildlife Conservation Impact)

3. Critical PWA Configuration for Subpages Important

Because the app contains deep subpages (like /squad/players), the PWA configuration must be carefully pointed to the absolute base directory so deep routing deep-links do not break upon a fresh update or reload.

Vite Router Base & Manifest Sync (vite.config.js):

manifest: {
  name: "uwa fc",
  short_name: "uwa fc",
  start_url: "/index.html", // Maps explicitly to the entry shell file
  display: "standalone",
  scope: "/" // Ensures the PWA handles all subpages and sub-routes seamlessly
}

Main Matrix Shell Entry Point (index.html):

<!-- Absolute root linking prevents subpages from looking for manifest relatively -->
<link rel="manifest" href="/manifest.json">

<!-- Native iOS Mobile App Override Titles -->
<meta name="apple-mobile-web-app-title" content="uwa fc">

4. Testing Routing & Updates on Local Workstations

When clicking deep-nested subpages, local service worker caching profiles can occasionally preserve outdated route paths. To forcefully audit new UI or route adjustments immediately during presentation checks:

  • Launch Chrome Developer tools via F12 or right click Inspect.
  • Navigate straight into the Application panel selection block.
  • Select Storage options in the left-hand navigation list menu tree.
  • Click Clear site data and cleanly refresh the active layout wrapper.

5. Presentation Deployment Guidelines

  • Router Fallback: If showcasing the project via a built preview version, ensure your local server or hosting solution redirects all subpage requests back to /index.html to allow the router to resolve pages properly without dropping 404 errors.
  • Responsive Demonstration: Leverage simulated mobile layouts inside inspection tools to display target responsiveness optimizations directly across high-density devices.
